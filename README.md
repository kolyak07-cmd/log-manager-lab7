# Log Manager (лабораторная работа)

Bash-скрипт, который проверяет заполнение диска и архивирует старые логи.

## Файлы
- `log_manager.sh` — основной скрипт
- `test_log_manager.sh` — тесты

## Использование
./log_manager.sh <папка> <порог_%> <M>

- папка — путь к папке с логами
- порог_% — порог заполнения диска (0-100)
- M — сколько самых старых .log файлов архивировать

## Как работает
1. Проверяет аргументы и существование папки.
2. Выводит заполнение раздела, на котором лежит папка (df).
3. Если заполнение больше порога, отбирает M самых старых файлов *.log
   и архивирует их в tar.gz в папку /backup.
4. Иначе выводит "Заполнение в норме".

## Примеры
./log_manager.sh ~/mylogs 90 2   # заполнение в норме, архива нет
./log_manager.sh ~/mylogs 0 2    # порог превышен, архив создан
